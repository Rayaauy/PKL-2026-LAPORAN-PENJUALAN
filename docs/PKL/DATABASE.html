Database Schema

7 tables with relationships and constraints

Tables

users

User accounts and authentication.

Column Type Notes
id INT PRIMARY KEY Auto-increment
name VARCHAR(255) User name
email VARCHAR(255) UNIQUE For login
password VARCHAR(255) Hashed (bcrypt)
is_admin BOOLEAN Admin flag
created_at, updated_at TIMESTAMP Auto-managed

business_profiles

UMKM/business information. One per user (1:1 relationship).

Column Type Notes
id INT PRIMARY KEY
user_id INT UNIQUE FK References users (cascade delete)
business_name VARCHAR(255) Required
owner_name VARCHAR(255) Optional
address, phone TEXT, VARCHAR(15) Optional

categories

Product categories. Per-user scoped.

Column Type Notes
id INT PRIMARY KEY
user_id INT FK References users (cascade delete)
name VARCHAR(255) Required
description TEXT Optional

products

Inventory. Per-user, optional category.

Column Type Notes
id INT PRIMARY KEY
user_id INT FK References users
category_id INT FK NULLABLE References categories (set null)
name VARCHAR(255) Required
price DECIMAL(15,2) Required, >= 0
stock INT Informational only
unit VARCHAR(50) pcs, box, kg, etc
is_active BOOLEAN Toggle without deleting

transactions

Sales transactions. Per-user, multiple items each.

Column Type Notes
id INT PRIMARY KEY
user_id INT FK References users
transaction_code VARCHAR(255) UNIQUE TRX-YYYYMMDD-XXXXX
transaction_date DATE Required
total_amount DECIMAL(15,2) Sum of subtotals
notes TEXT Optional

transaction_items

Line items in a transaction. Stores price snapshot.

Column Type Notes
id INT PRIMARY KEY
transaction_id INT FK References transactions (cascade)
product_id INT FK References products (restrict)
product_name VARCHAR(255) Snapshot for history
price DECIMAL(15,2) Snapshot at time of sale
quantity INT Required, >= 1
subtotal DECIMAL(15,2) quantity × price

blog_posts

Public blog content. Admin-only creation.

Column Type Notes
id INT PRIMARY KEY
title VARCHAR(255) Required
slug VARCHAR(255) UNIQUE URL-friendly
content LONGTEXT Blog body
published_at TIMESTAMP NULL NULL = draft

Query Examples

Get user's total revenue

SELECT SUM(total_amount) 
FROM transactions 
WHERE user_id = ?;

Get top selling products

SELECT product_id, product_name, SUM(quantity) as qty_sold
FROM transaction_items
WHERE transaction_id IN (
    SELECT id FROM transactions WHERE user_id = ?
)
GROUP BY product_id, product_name
ORDER BY qty_sold DESC
LIMIT 10;

Get low stock products

SELECT * FROM products 
WHERE user_id = ? AND stock < 5 AND is_active = true;

Get transaction with items (eager loaded)

// Laravel Eloquent
Transaction::with('items.product')
    ->where('user_id', $userId)
    ->find($id);

Indexing

Auto-indexed by database:

  • All PRIMARY KEYs
  • All FOREIGN KEYs
  • UNIQUE columns (email, transaction_code, slug)

Additional indexes recommended:

CREATE INDEX idx_products_user_id ON products(user_id);
CREATE INDEX idx_transactions_user_id ON transactions(user_id);
CREATE INDEX idx_transaction_items_transaction_id ON transaction_items(transaction_id);
