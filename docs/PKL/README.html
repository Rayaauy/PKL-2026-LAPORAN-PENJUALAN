UMKM Sales System

Sales tracking web application for small businesses (UMKM) in Indonesia

What it does: User registration, inventory management, transaction recording, sales reporting, and admin blog management.

Quick Start

# Install
composer install
npm install

# Setup
cp .env.example .env
php artisan key:generate

# Database
bash scripts/setup-database.sh

# Run
php artisan serve

Access at http://localhost:8000

Features

Authentication

  • User registration with email validation
  • Login with password hashing (bcrypt)
  • Admin authorization
  • Rate limiting on auth endpoints

Inventory

  • CRUD categories & products
  • Stock tracking
  • Multi-unit support
  • Active/inactive toggle

Transactions

  • Multi-item transactions
  • Auto-calculated totals
  • Unique transaction codes
  • Transaction history

Reports

  • Revenue summary
  • Top selling products
  • CSV export
  • Per-user data isolation

Database

7 main tables with relationships:

  • users — User accounts
  • business_profiles — UMKM info (1:1 with users)
  • categories — Product categories
  • products — Product inventory
  • transactions — Sales transactions
  • transaction_items — Line items
  • blog_posts — Blog content

See Database.html for full schema.

Setup Prerequisites

  • PHP 8.2+
  • MySQL 5.7+ or MariaDB
  • Composer
  • Node.js 18+

Running Locally

# 1. Clone/enter project
cd umkm-sales

# 2. Install dependencies
composer install
npm install

# 3. Environment
cp .env.example .env
php artisan key:generate

# 4. Database
mysql -u root -p -e "CREATE DATABASE umkm_sales;"
bash scripts/setup-database.sh

# 5. Build & serve
npm run dev
php artisan serve

# 6. Access http://localhost:8000

Security

  • CSRF tokens on all forms
  • Password hashing (bcrypt)
  • User ownership validation
  • SQL injection prevention (Eloquent ORM)
  • Rate limiting on auth

Performance

  • Eager loading relationships
  • Foreign key indexing
  • Pagination on list views
  • Query optimization

Testing

php artisan test
php artisan test --filter=ProductTest
php artisan test --filter=store

Troubleshooting

MySQL access denied (SQLSTATE[1698])

Use sudo mysql to access, or configure Laravel to use file drivers for cache/session.

Port 8000 in use

php artisan serve --port=8080

Node modules issue

npm cache clean --force
rm -rf node_modules package-lock.json
npm install
