👥 User Flow Diagram

Alur Interaksi Pengguna pada Aplikasi UMKM Sales

🌐 Public User Flow

1. Kunjungi Homepage
Pengguna mengakses halaman utama aplikasi
↓
2. Baca Blog
Lihat artikel dan tips UMKM dari blog publik
↓
Apakah sudah login?
✗ Tidak → Lanjut ke Register
✓ Ya → Ke Dashboard
↓
3. Login/Register
Buat akun atau masuk ke sistem

📊 Admin/Moderator Flow

1. Admin Login
Masuk dengan akun admin/moderator
↓
2. Admin Dashboard
Kelola blog dan konten publik
↓
Opsi Manajemen:
• Buat artikel blog
• Edit/hapus postingan
• Publikasikan konten

👤 Authenticated User (UMKM Owner) Flow

1
Login
Masuk dengan email & password. Validasi kredensial di database
2
Dashboard
Tampilan ringkas: total penjualan, transaksi terbaru, produk aktif
3
Setup Profil Bisnis
Input data UMKM: nama, pemilik, alamat, kontak (sekali saja)
4
Kelola Kategori
CRUD kategori produk: tambah, ubah, hapus kategori
5
Kelola Produk
Manajemen inventaris: harga, stok, satuan, status aktif
6
Catat Transaksi
Input penjualan: pilih produk, qty, hitung subtotal otomatis
7
Lihat Laporan
Analisis penjualan: grafik, total revenue, export data
8
Logout
Keluar dari sistem dengan aman

💳 Proses Input Transaksi Detail

1. Buka Form Transaksi
Navigasi ke halaman Transactions
↓
2. Input Data Transaksi
• Tanggal penjualan
• Catatan (opsional)
↓
3. Tambah Item Penjualan
Pilih produk → qty → harga tersimpan
↓
4. Kalkulasi Otomatis
Subtotal = Qty × Harga Produk
↓
5. Simpan Transaksi
Generate transaction_code unik
↓
✓ Transaksi Tersimpan
Redirect ke list transaksi

📈 Report & Export Flow

1. Akses Laporan
Menu Reports → Lihat overview
↓
2. Filter Data (Opsional)
• Range tanggal
• Kategori produk
↓
3. Lihat Statistik
• Total penjualan
• Produk terlaris
• Grafik trend
↓
Ingin Export?
✓ Ya → Download CSV
✗ Tidak → Tutup
↓
✓ File CSV Diunduh
Siap analisis di Excel/Sheets
