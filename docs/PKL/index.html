Troubleshooting

MySQL access denied (SQLSTATE[1698]): Gunakan sudo mysql atau set CACHE_STORE=file dan SESSION_DRIVER=file di .env.
Port 8000 occupied: php artisan serve --port=8080
# Node modules error
npm cache clean --force
rm -rf node_modules package-lock.json
npm install

🏗 MVC & Request Flow

HTTP Request ↓ routes/web.php (Route matching) ↓ Middleware (Auth check, rate limit) ↓ Controller (Request handling + validation) ↓ Model (Database queries) ↓ Database (MySQL/MariaDB) ↓ Model returns data ↓ View (Blade template) (Rendering) ↓ HTTP Response (HTML ke browser)

Contoh: Membuat Produk

1. User submit form
   POST /products

2. Route matching
   Route::post('/products', [ProductController::class, 'store'])

3. Middleware checks
   - auth: User logged in?
   - throttle: Rate limit OK?

4. Controller processes
   ProductController::store()
   - Validate input
   - Get auth user
   - Create Product model
   - Save to database

5. Model relationships
   Product belongsTo User
   Product belongsTo Category
   Product hasMany TransactionItems

6. Response
   Redirect /products with success message

Data Isolation

Semua query otomatis difilter berdasarkan user_id. User A tidak bisa akses data User B.

// Products
$products = Product::where('user_id', auth()->id())->get();

// Transactions
$transactions = Transaction::where('user_id', auth()->id())->get();

// Reports
$revenue = Transaction::where('user_id', auth()->id())->sum('total_amount');

Performance — Eager Loading

// BAD: N+1 queries (lambat)
$products = Product::all();
foreach ($products as $p) echo $p->category->name;

// GOOD: 2 queries saja
$products = Product::with('category')->get();

🔐 Autentikasi & Autorisasi

Login Flow

Login form submission ↓ LoginController::login() ↓ Hash(password) == users.password di DB? ↓ Session dibuat Simpan user_id ke session/cookie ↓ Redirect ke /dashboard ↓ Session persist di setiap request Logout → clear session

Middleware-based (route level)

Route::middleware('auth')...        // Butuh login
Route::middleware('admin')...       // Butuh is_admin=true
Route::middleware('throttle:60,1')  // Rate limit 60/menit

Model-based (resource level)

// Cek ownership di controller
$product = Product::find($id);
if ($product->user_id !== auth()->id()) {
    abort(403);  // User bukan pemilik resource ini
}

Error Handling

// Validation error
$validated = $request->validate([
    'name'  => 'required|string|max:255',
    'price' => 'required|numeric|min:0',
]);
// Returns 422 dengan error messages jika invalid

// Authorization error
abort(403); // Forbidden — user bukan pemilik
abort(404); // Not Found — resource tidak ada

Cascade Delete

ON DELETE CASCADE

Jika user dihapus:

  • Semua categories terhapus
  • Semua products terhapus
  • Semua transactions terhapus
  • Semua items terhapus

ON DELETE SET NULL

Jika category dihapus:

  • products.category_id → NULL
  • Product tetap ada (tidak terhapus)

ON DELETE RESTRICT

Jika product ada di transaksi:

  • Delete diblokir
  • Mencegah kehilangan data

Query Examples

-- Total revenue user
SELECT SUM(total_amount) FROM transactions WHERE user_id = ?;

-- Top selling products
SELECT product_id, product_name, SUM(quantity) as qty_sold
FROM transaction_items
WHERE transaction_id IN (SELECT id FROM transactions WHERE user_id = ?)
GROUP BY product_id, product_name
ORDER BY qty_sold DESC LIMIT 10;

-- Low stock products
SELECT * FROM products WHERE user_id = ? AND stock < 5 AND is_active = true;

📊 Database Flow

1. Data Flow: User Registration

INPUT User submit form: name, email, password
↓
VALIDASI Email valid · Email belum ada di DB · Password min 8 chars & confirmed
↓
PROSES Hash password dengan bcrypt · Set is_admin = false (default)
↓
INSERT INSERT INTO users (name, email, password, is_admin, created_at, updated_at) VALUES (…)
↓
OUTPUT ✓ User account created · ✓ Redirect ke login page

2. Data Flow: Create Transaction

Catatan: Setiap transaction_item menyimpan snapshot product_name dan price pada saat transaksi. Jika product price berubah nanti, history transaksi tetap akurat.
INPUT transaction_date: 2024-01-10 · notes: Penjualan offline
↓
INSERT INSERT INTO transactions (user_id, transaction_date, notes, created_at) → Generated code: TRX-20240110-00001
↓
ITEM 1 Product: Laptop Dell (ID:42) · Qty: 2 · Price: 8.500.000 · Subtotal: 17.000.000
↓
INSERT INSERT INTO transaction_items (transaction_id, product_id, product_name, price, quantity, subtotal) VALUES (15, 42, 'Laptop Dell', 8500000, 2, 17000000)
↓
ITEM 2 Product: Mouse Wireless (ID:35) · Qty: 3 · Price: 150.000 · Subtotal: 450.000
↓
INSERT INSERT INTO transaction_items … VALUES (15, 35, 'Mouse Wireless', 150000, 3, 450000)
↓
HITUNG total_amount = 17.000.000 + 450.000 = 17.450.000
↓
UPDATE UPDATE transactions SET total_amount = 17450000 WHERE id = 15
↓
✓ Transaction TRX-20240110-00001 · Total Rp 17.450.000 · 2 items recorded

3. Data Flow: Generate Report

REQUEST User klik /reports
↓
QUERY 1 SELECT SUM(total_amount) FROM transactions WHERE user_id = 1 → Rp 125.500.000
↓
QUERY 2 SELECT product_name, SUM(quantity) FROM transaction_items … GROUP BY product_id ORDER BY total_qty DESC → Top 10 produk
↓
QUERY 3 SELECT COUNT(*) FROM transactions WHERE user_id = 1 → 42 transactions
↓
RENDER Total Revenue: Rp 125,5 juta · Transaction Count: 42 · Top Products Chart · Monthly Trend
↓
EXPORT Download transactions.csv untuk analisis di Excel
